# 카드 거래 이력 분석 — 신규 브랜드 입점 상권 검토

## 배경
A사가 신규 브랜드 점포를 후보 지역 A에 입점할지 정하려 한다. 신규 브랜드라 과거 상권 정보가 없어,
신용카드 Spending 데이터로 그 지역 고객의 소비 성향을 파악하고 브랜드 성향과 맞는지 비교한다.

| 항목 | 내용 |
|---|---|
| 문제 정의 | 신규 브랜드 입점 상권 불분명 |
| 기대 효과 | 입점 여부 결정, 상권 고객 소비 성향 파악 |
| 성과 측정 | 신규 진입 결정 여부 |

## 데이터
상점별 카드 Spending 데이터 (`S_PJT04_DATA.csv`, 저장소에는 포함하지 않음)

| 컬럼 | 설명 |
|---|---|
| `store_id` | 상점 ID |
| `date`, `time` | 거래 날짜·시간 |
| `card_id` | 카드 ID |
| `amount` | 매출액 (음수는 거래 취소) |
| `installments` | 할부 개월 (일시불은 빈 문자열) |
| `days_of_week` | 요일 (월요일 0 ~ 일요일 6) |
| `holyday` | 공휴일 여부 |

## 분석 내용
1. 상점별 결제 금액·이용 고객 수로 핵심 업종(상위 5개) 선정
2. 요일별 매출 패턴
3. 업종별 취소 금액·취소 건수
4. 핵심 업종의 연도별·날짜별 매출 비중
5. 핵심 업종별 주요 고객(결제 금액 상위 카드)

## 결과
노트북에 결론 정리 셀은 없다. 분석 결과와 입점 판단은 노트북의 표·그래프에서 확인한다.
